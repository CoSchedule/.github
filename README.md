# CoSchedule/.github

Org-wide defaults that GitHub applies to every CoSchedule repo that doesn't have its own copy:

| File | What it does |
|---|---|
| `PULL_REQUEST_TEMPLATE.md` | The default PR template |
| `ISSUE_TEMPLATE/` | Issue forms for bugs, features and chores, with acceptance criteria |
| `CONTRIBUTING.md` | How we branch, commit, review and build with AI |
| `SECURITY.md` | How to report a security problem |
| `workflow-templates/` | Starter workflows under **Actions > New workflow** in every org repo |

GitHub only applies these from a public `.github` repo, so everything here is safe to be public. The shared workflows and the repo standard are internal and live in a private repo.
